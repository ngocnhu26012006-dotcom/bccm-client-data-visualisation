# Client Data Visualisation Project — BCCM

**Status:** In Progress | August–November 2026

## Project Overview

An ongoing client-based Business Analytics project exploring how data visualisation can support different stakeholder information needs within Australia's co-operative and mutual sector.

## Objectives

- Identify information needs across three stakeholder personas.
- Explore data from more than 50 co-operative and mutual organisations.
- Develop stakeholder-focused visualisations using Python and Tableau.
- Apply data quality and ethical data-handling principles.

## My Contributions

- Conducted stakeholder and persona analysis.
- Contributed to identifying nine stakeholder-focused business questions.
- Worked on data sourcing, structuring and quality assessment.
- Developed visual insights and recommendations for future data applications.

## Tools & Methods

Python, Tableau, Data Visualisation, Persona Analysis, Data Quality Assessment, PAPA Framework.
